VLA · Campus model & Driver Agent 2025.1 – 2026.3

Owner of the VLA campus model & Driver Agent model (19-person team); since 2025.7 owner of the static Lane model, on-vehicle + cloud

  • Campus VLA model: unified driving VLA architecture (OneModel + VLM + Diffusion Policy) solving gate entry/exit, campus navigation and narrow-road yielding; scene separation via encoded scene information and prompt switching, forming a unified driving-parking architecture.
  • Driver Agent model: multi-agent architecture from 0 to 1 on a Qwen-2.5-VL 7B base; pre/post-training inject driving knowledge; understands and executes acceleration, lane change, turns, following distance, overtaking (single and combined instructions); RAG-based preference memory.
  • On-vehicle static road model: MapQR structure with multiple improvements; led lane-type optimization (+5%), SD map fusion (+3%) and migration to a sparse model.
  • Cloud auto-labeling: Gaussian BEV + mapping — 4D Gaussian ground reconstruction, Gaussian BEV model (+5%), aggregated mapping and automated QC → +30% effective efficiency on 4D lane/centerline/topology auto-labeling.

Result: VLA OTA-pushed to customers in 2025.9 — the first company in China to fully roll out VLA to all users.
